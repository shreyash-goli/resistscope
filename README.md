# ResistScope

Resistance-aware triage tool for antiviral compounds targeting HIV-1 protease.

## Setup

ResistScope relies on a scientific stack (RDKit, OpenMM, PDBFixer, AutoDock
Vina, Meeko) that is best installed with conda. Create the environment from
[`environment.yml`](environment.yml):

```bash
conda env create -f environment.yml
conda activate resistscope
```
